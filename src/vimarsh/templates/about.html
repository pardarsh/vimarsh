How Vimarsh works

Sources

Bills come only from the official listings of the Parliament of India at sansad.in. For each bill Vimarsh takes its most recent official text: as passed by both houses, as passed by one house, or as introduced. No third-party summaries are used.

Analysis

The text is extracted locally and sent to a language model with a fixed, versioned prompt that asks for a neutral, factual description of what the bill does, returned as structured JSON. Very long bills are cut to their beginning and end (which hold the clauses, the Statement of Objects and Reasons and the Financial Memorandum) and marked as partial analyses.

Provenance

Every analysis records the official document URL, SHA-256 hashes of the document and of the extracted text, the provider, the requested and served model, the provider's response ID, the generation settings (temperature, thinking level), token usage including thinking tokens, how long the call took and how many attempts it needed, any fallback from another provider, the prompt and schema versions with a hash of both, the software versions, and a link to the public GitHub Actions run that produced it. Where the model provides one, its own summary of its reasoning is published too. Anyone can download the official text, check its hash and rerun the analysis. Everything is kept in the public git repository, so every change has history.

Updates

The pipeline runs daily. When a new stage of a bill is published (for example the passed text), the bill is analysed again and its page is updated. Subscribe through the RSS feed, or use the machine-readable bills.json.

Limits
